Experiment 17: Database Connection

Node.js and Express.js Practical Program

Aim

To understand how to connect a Node.js application with MongoDB.

Theory

MongoDB is a NoSQL database used to store data in document format. Mongoose is a Node.js library used to connect and work with MongoDB.

Required Package

npm install mongoose

Program

const mongoose = require("mongoose");

mongoose.connect("mongodb://127.0.0.1:27017/studentDB")
    .then(() => {
        console.log("MongoDB connected successfully");
    })
    .catch((error) => {
        console.log("Database connection failed");
    });

Execution Commands

npm install mongoose
node database-connection.js

Sample Output

MongoDB connected successfully

Explanation

  • mongoose: Connects Node.js with MongoDB.
  • mongoose.connect(): Establishes database connection.
  • then(): Executes when connection is successful.
  • catch(): Handles connection errors.

Result

Thus, a MongoDB connection was implemented using Mongoose.
