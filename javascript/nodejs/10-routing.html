Experiment 10: Routing in Express.js

Aim

To create multiple routes in an Express.js application.

Theory

Routing determines how an application responds to client requests for different URL paths. Express.js uses methods such as app.get() to define routes.

Program

const express = require("express");

const app = express();

const PORT = 5000;

app.get("/", (req, res) => {
    res.send("Welcome to the Home Page");
});

app.get("/students", (req, res) => {
    res.send("This is the Students Page");
});

app.get("/contact", (req, res) => {
    res.send("This is the Contact Page");
});

app.listen(PORT, () => {
    console.log(`Routing server running at http://localhost:${PORT}`);
});

Execution Command

node routing-demo.js

Available Routes

  • / - Home Page
  • /students - Students Page
  • /contact - Contact Page

Sample Output

Routing server running at http://localhost:5000

Result

Thus, multiple routes were successfully created and tested using Express.js.
