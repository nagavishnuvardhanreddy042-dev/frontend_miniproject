Experiment 19: REST API

Node.js and Express.js Practical Program

Aim

To create a simple REST API using Node.js and Express.js.

Theory

REST API allows applications to communicate with each other using HTTP methods. Data is commonly returned in JSON format.

Program

const express = require("express");

const app = express();

const PORT = 7700;

app.get("/api/student", (req, res) => {
    res.json({
        id: 1,
        name: "Akshara",
        course: "Computer Science"
    });
});

app.listen(PORT, () => {
    console.log(`REST API running at http://localhost:${PORT}`);
});

Execution Command

node rest-api.js

Browser URL

http://localhost:7700/api/student

Sample Output

{
    "id": 1,
    "name": "Akshara",
    "course": "Computer Science"
}

Explanation

  • app.get(): Creates a GET API endpoint.
  • /api/student: API route.
  • res.json(): Sends JSON data to the client.
  • PORT 7700: Server runs on port 7700.

Result

Thus, a simple REST API was successfully created using Node.js and Express.js.
