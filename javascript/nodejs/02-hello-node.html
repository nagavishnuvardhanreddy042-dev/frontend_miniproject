Hello World using Node.js

Experiment 2

Aim

To write and execute a simple JavaScript program using Node.js.

Program

console.log("Hello World from Node.js!");

Steps to Execute

  1. Create a JavaScript file named hello.js.
  2. Write the program inside the file.
  3. Open the terminal in that folder.
  4. Run the command: node hello.js

Expected Output

Hello World from Node.js!
