Experiment 16: Sessions in Express.js

Node.js and Express.js Practical Program

Aim

To understand and implement sessions in an Express.js application.

Theory

Sessions are used to store user information temporarily on the server while the user is visiting a website.

Required Package

npm install express-session

Program

const express = require("express");
const session = require("express-session");

const app = express();

const PORT = 7500;

app.use(session({
    secret: "my-secret-key",
    resave: false,
    saveUninitialized: true
}));

app.get("/", (req, res) => {
    req.session.studentName = "Akshara";
    res.send("Session data has been stored.");
});

app.get("/read-session", (req, res) => {
    res.send("Session Value: " + req.session.studentName);
});

app.listen(PORT, () => {
    console.log(`Session server running at http://localhost:${PORT}`);
});

Execution Commands

npm install express-session
node sessions.js

Browser URLs

http://localhost:7500
http://localhost:7500/read-session

Explanation

  • express-session: Provides session functionality.
  • req.session: Stores and reads session data.
  • secret: Used to secure the session.
  • Session data is maintained while the session is active.

Result

Thus, sessions were successfully implemented using Express.js.
