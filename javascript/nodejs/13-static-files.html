Experiment 13: Serving Static Files

Node.js and Express.js Practical Program

Aim

To serve static files such as HTML, CSS, and images using Express.js.

Theory

Express.js provides the express.static() middleware to serve static files from a folder.

Program

const express = require("express");

const path = require("path");

const app = express();

const PORT = 7200;

app.use(express.static(path.join(__dirname, "public")));

app.listen(PORT, () => {
    console.log(`Static file server running at http://localhost:${PORT}`);
});

Execution Command

node static-files.js

Sample Console Output

Static file server running at http://localhost:7200

Browser Output

The files inside the public folder can be accessed through the browser.

Explanation

  • express.static(): Serves static files.
  • path.join(): Creates the correct folder path.
  • __dirname: Represents the current directory.
  • The public folder contains static files.

Result

Thus, static files were successfully served using Express.js.
