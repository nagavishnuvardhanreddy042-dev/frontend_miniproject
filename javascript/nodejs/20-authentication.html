Experiment 20: Authentication

Node.js and Express.js Practical Program

Aim

To implement basic username and password authentication using Node.js and Express.js.

Theory

Authentication is the process of verifying the identity of a user using login credentials such as username and password.

Program

const express = require("express");

const app = express();

const PORT = 7800;

app.use(express.json());

const username = "admin";
const password = "1234";

app.post("/login", (req, res) => {
    if (
        req.body.username === username &&
        req.body.password === password
    ) {
        res.send("Login successful");
    } else {
        res.status(401).send("Invalid username or password");
    }
});

app.listen(PORT, () => {
    console.log(`Authentication server running at http://localhost:${PORT}`);
});

Execution Command

node authentication.js

API URL

http://localhost:7800/login

Login Credentials

Username: admin
Password: 1234

Sample Output

Login successful

Result

Thus, basic user authentication was successfully implemented using Node.js and Express.js.
