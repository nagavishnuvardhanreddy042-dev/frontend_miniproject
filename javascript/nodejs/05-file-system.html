File System Module

Experiment 5

Aim

To create and write data into a file using the Node.js File System module.

Theory

The File System module, represented as fs, is a built-in Node.js module used to create, read, update, delete and manage files.

Module Used

fs

Important Method

fs.writeFileSync()

Execution Command

node file-demo.js

Expected Output

File created and data written successfully.
