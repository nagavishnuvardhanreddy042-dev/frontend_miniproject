Experiment 8: Express.js Introduction

Aim

To create a simple web server using the Express.js framework.

Theory

Express.js is a web application framework for Node.js. It simplifies server creation, routing, request handling, and API development.

Installation

npm install express

Program

const express = require("express");

const app = express();

const PORT = 3000;

app.get("/", (req, res) => {
    res.send("Hello! This is my first Express.js application.");
});

app.listen(PORT, () => {
    console.log(`Express server running at http://localhost:3000`);
});

Execution Command

node express-demo.js

Console Output

Express server running at http://localhost:3000

Browser Output

Hello! This is my first Express.js application.

Explanation

  • require("express"): Imports Express.js.
  • express(): Creates an Express application.
  • app.get("/"): Handles requests to the home route.
  • res.send(): Sends a response to the browser.
  • app.listen(): Starts the server.

Result

Thus, a simple Express.js server was successfully created and accessed through the browser.
