Node.js Installation and Setup

Experiment 1

Aim

To install Node.js and verify the installation using the terminal.

Steps

  1. Download and install Node.js.
  2. Open VS Code terminal.
  3. Check the Node.js version.
  4. Check the npm version.

Commands

node -v

npm -v

Expected Output

v24.x.x
11.x.x

Explanation

Node.js allows JavaScript code to run outside the browser. npm stands for Node Package Manager and is used to install and manage packages.
