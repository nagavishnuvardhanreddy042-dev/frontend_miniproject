Experiment 12: Request and Response

Node.js and Express.js Practical Program

Aim

To understand how request and response objects work in Express.js.

Theory

The request object contains information sent by the client. The response object is used by the server to send data back to the client.

Program

const express = require("express");

const app = express();

const PORT = 7100;

app.get("/", (req, res) => {
    res.send("This is the Home Page");
});

app.get("/student", (req, res) => {
    res.send("Student Name: Akshara");
});

app.listen(PORT, () => {
    console.log(`Request-Response server running at http://localhost:${PORT}`);
});

Execution Command

node request-response.js

Sample Console Output

Request-Response server running at http://localhost:7100

Browser URLs

http://localhost:7100
http://localhost:7100/student

Browser Output

  • Home Page: This is the Home Page
  • Student Page: Student Name: Akshara

Explanation

  • req: Stores client request information.
  • res: Sends a response to the client.
  • res.send(): Sends text to the browser.
  • Different URLs produce different responses.

Result

Thus, request and response objects were successfully implemented in Express.js.
