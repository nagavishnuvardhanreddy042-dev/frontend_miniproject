Experiment 11: Middleware in Express.js

Node.js and Express.js Practical Program

Aim

To understand and implement middleware in an Express.js application.

Theory

Middleware functions execute between the request and the response. They can access the request object, response object, and the next() function.

Syntax

app.use((req, res, next) => {
    // Middleware code
    next();
});

Program

const express = require("express");

const app = express();

const PORT = 7000;

app.use((req, res, next) => {
    console.log("Middleware executed");
    next();
});

app.get("/", (req, res) => {
    res.send("Welcome to the Middleware Demo");
});

app.listen(PORT, () => {
    console.log(`Middleware server running at http://localhost:${PORT}`);
});

Execution Command

node middleware-demo.js

Sample Console Output

Middleware server running at http://localhost:7000
Middleware executed

Browser Output

Welcome to the Middleware Demo

Explanation

  • app.use(): Registers middleware.
  • req: Represents the client request.
  • res: Represents the server response.
  • next(): Passes control to the next function.
  • The middleware runs before the route response.

Result

Thus, middleware was successfully implemented in Express.js.
