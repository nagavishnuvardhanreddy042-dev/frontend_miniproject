Experiment 15: Cookies in Express.js

Node.js and Express.js Practical Program

Aim

To understand and implement cookies in an Express.js application.

Theory

Cookies are small pieces of data stored in the user's browser. They help websites remember user information.

Required Package

npm install cookie-parser

Program

const express = require("express");
const cookieParser = require("cookie-parser");

const app = express();

const PORT = 7400;

app.use(cookieParser());

app.get("/", (req, res) => {
    res.cookie("studentName", "Akshara");
    res.send("Cookie has been created successfully.");
});

app.get("/read-cookie", (req, res) => {
    res.send("Cookie Value: " + req.cookies.studentName);
});

app.listen(PORT, () => {
    console.log(`Cookie server running at http://localhost:${PORT}`);
});

Execution Commands

npm install cookie-parser
node cookies.js

Sample Console Output

Cookie server running at http://localhost:7400

Browser URLs

http://localhost:7400
http://localhost:7400/read-cookie

Explanation

  • cookie-parser: Reads cookies from requests.
  • res.cookie(): Creates a cookie.
  • req.cookies: Reads cookie values.
  • Cookies are stored in the browser.

Result

Thus, cookies were successfully created and read using Express.js.
