Experiment 7: NPM in Node.js

Aim

To understand and use NPM commands for managing Node.js projects and packages.

Introduction

NPM stands for Node Package Manager. It is used to install, update, remove and manage packages in Node.js applications.

Important NPM Commands

npm -v
npm init -y
npm install package-name
npm uninstall package-name
npm list

Commands Executed

node -v
npm -v
npm init -y

Sample Output

Node.js version: v24.18.1
NPM version: 11.16.0

package.json created successfully

Explanation

  • node -v: Displays the installed Node.js version.
  • npm -v: Displays the installed NPM version.
  • npm init -y: Creates a package.json file automatically.
  • package.json: Stores project information and dependencies.

Files Created

  • package.json

Result

Thus, NPM was successfully checked and a Node.js project was initialized using the npm init -y command.
