Experiment 14: Handling Form Data

Node.js and Express.js Practical Program

Aim

To receive and process form data submitted by the client using Express.js.

Theory

Express.js uses express.urlencoded() middleware to read data submitted through HTML forms.

Program

const express = require("express");

const app = express();

const PORT = 7300;

app.use(express.urlencoded({ extended: true }));

app.get("/", (req, res) => {
    res.send(`
        <h1>Student Form</h1>
        <form method="POST" action="/submit">
            <input type="text" name="studentName"
            placeholder="Enter your name" required>
            <br><br>
            <button type="submit">Submit</button>
        </form>
    `);
});

app.post("/submit", (req, res) => {
    res.send("Welcome, " + req.body.studentName);
});

app.listen(PORT, () => {
    console.log(`Form server running at http://localhost:${PORT}`);
});

Execution Command

node form-data.js

Sample Console Output

Form server running at http://localhost:7300

Browser URL

http://localhost:7300

Explanation

  • express.urlencoded(): Reads form data.
  • req.body: Contains submitted form values.
  • app.post(): Handles form submission.
  • res.send(): Sends the result to the browser.

Result

Thus, form data was successfully received and processed using Express.js.
