Three Types of CSS

Experiment 1: Inline, Internal and External CSS

Inline CSS

Inline CSS is written directly inside the style attribute of an HTML element.

Internal CSS

Internal CSS is written inside the <style> tag in the HTML head section.

External CSS

External CSS is written in a separate CSS file and connected using the link tag.

This card, header, buttons and page layout are styled using the external style.css file.
